PROJECT_01 // MULTIPLAYER_GAME

Fangs and Fists

C++ / Makeblock / Arduino

Fangs and Fists é um jogo de luta multiplayer estilo arcade que combina combate em tempo real com um sistema de cartas escaneáveis de personagens e poderes. O projeto foi desenvolvido com foco em design acessível e inclusivo, pensado para oferecer uma experiência mais confortável para jovens com TEA e TDAH, priorizando clareza visual, ritmo ajustado e redução de sobrecarga sensorial. Fangs and Fists is an arcade-style multiplayer fighting game that combines real-time combat with a system of scannable character and power cards. The project was developed with a focus on accessible and inclusive design, tailored to offer a more comfortable experience for youth with ASD and ADHD, prioritizing visual clarity, adjusted pacing, and sensory overload reduction.

PROJECT_03 // AUTOMATION_CORE

Hyrox Planner

Python / Data / Automation

Sistema desenvolvido em Python planejado para a automatização, organização e arquivamento de planilhas de treino de atletas na modalidade HYROX. O script analisa dados de desempenho, otimiza as rotinas de preparação e gera relatórios de evolução de forma limpa e eficiente. A system developed in Python engineered to automate, organize, and archive training schedules for HYROX athletes. The script analyzes performance data, optimizes prep routines, and generates efficiency evolution reports.
